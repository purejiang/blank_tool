# 07 - UI 设计规范（Stitch 设计产出指引）

> 状态 = 设计产出指引，设计稿未落地；产出物放入 `.omo/designs/`，由分期计划 T24 实施。设计契约（第 8 轮决策，2026-08-04）：**功能保真是硬约束**（IA、页面、流程、空状态、三模式主题机制）；**视觉语言以用户确认的 Google Stitch 设计稿为准**，Stitch 可自由发挥。Naive UI 仍是组件底座，CSS 变量主题机制保留（不硬编码颜色），应用名/productName 不变。

## 1. 信息架构与外壳（已决策，不可偏离）

- 四个一级模块 + 路由：工作流 `/workflows`（管理列表 + 二级编辑器 `/workflows/editor/:name?`）、任务 `/tasks`、工具 `/tools`（工具/环境双 tab）、设置 `/settings`；`/` 重定向到 `/workflows`；侧边栏 4 项导航。
- 外壳：左侧窄边栏（顶部应用名 Blank Tool、4 个带图标导航项、底部主题切换）+ 右侧内容区（页面标题 + 描述头 + 内容）。
- 退役边界：PackagePage/DevicePage/APK 一键等 Android 专属页面全部退役，UI 中不得出现任何 Android 专属入口或措辞（Android 能力仅存在于用户导入的 examples/ 内容）。

## 2. 屏幕清单与功能要求（6 屏 + 状态）

每屏列出**必须包含的功能元素**（设计可自由发挥视觉，功能元素不可删减）：

1. **工作流列表**：工具栏（新建工作流 主按钮 / 导入 / 导出 / 搜索）；工作流卡片网格（名称、一句话描述、节点数、最近更新、上次运行状态徽章、⋯ 菜单：编辑/复制/导出/删除）；空状态引导（导入示例工作流 / 新建工作流 两个按钮）。
2. **工作流编辑器**：点阵网格画布，节点为卡片（图标/节点名/工具名），纵向链式连边，选中态高亮；顶栏（返回、可编辑工作流名、保存、试运行 主按钮）；右侧节点设置面板：类型化表单（文本、文件/目录选择行、下拉）+ 表达式绑定展示（`$inputs.xxx`、`$nodes.<id>.outputs.xxx`）；面板底部 删除节点。
3. **任务 · 新建任务**：左列模板选择（`template.list`），右列按输入端口动态生成的表单（text/file-picker/folder-picker/bool/number/json/单选/多选），执行 主按钮；必填缺失时阻止启动并提示。
4. **任务 · 历史**：筛选栏（名称搜索 + 状态下拉 全部/运行中/成功/失败）；任务行（状态徽章：运行中/成功/失败、任务名、工作流名、开始时间、耗时）；可展开行 = 逐节点进度（✓/spinner/错误）+ 流式日志区；操作：取消 / 重新运行 / 删除。历史全保留，仅手动删除，无自动清理。
5. **工具管理**：顶部 tab 工具 | 环境。工具 tab：导入描述符 主按钮；工具卡片（图标、名称、来源徽章 内置/已导入、版本、操作数、⋯ 菜单：自定义路径/删除）；空状态引导（从 examples/ 导入工具描述符）。环境 tab：Java/Python/Node 行（检测路径、状态徽章 已检测/未配置、更改路径）。
6. **设置 + 关于**：分组表单——通用（请求超时 slider、系统通知 toggle 默认关）、外观（浅色/深色/自动 分段控件）、语言（简体中文/English）、路径配置（路径行 + 浏览按钮）；底部入口 诊断信息 / 关于。关于面板 = 通用运行时信息（应用/Electron/Node/Python 版本 + 后端健康状态徽章），不展示 bundled 工具版本。

- **通知约定**：任务完成/失败应用内 toast 始终开启；系统通知为设置开关、默认关。
- **主题**：浅色/深色/自动三模式，所有屏幕出两态（浅+深）。

## 3. Stitch 产出指引

- stitch.withgoogle.com，务必切 **Web** 模式（默认 App 是移动端）。
- 首屏生成后在 Edit Theme 里锁定主题（色板/圆角/字体），后续屏幕自动一致；方向不对就一句话换（如"换成更沉稳的专业工具风格"）。
- 一屏一条增量提示词生成；最后多选全部屏幕做全局统一 + 深色版。
- 文案跑偏成英文时：`把该屏所有界面文字改为简体中文`。
- 产出：设计稿截图放入 `.omo/designs/`（T24 消费）；可选 Figma/代码导出。

## 4. 提示词全集（直接粘贴）

以下 8 条为已批准提示词，**逐字使用，不要改写**：

① 首屏主提示词（建立外壳 + 工作流列表）：

```text
Design a desktop web application (1440×900): "Blank Tool" — a local workflow
orchestration app for developers and power users. All UI text in Simplified
Chinese (简体中文).

App shell (must stay identical on every screen): slim left sidebar — app name
"Blank Tool" at top; 4 nav items with icons: 工作流 (active), 任务, 工具, 设置;
theme switcher at bottom. Content area on the right with page title +
description header.

Screen: 工作流列表 (/workflows)
- Toolbar: primary button 新建工作流, secondary 导入 / 导出, search field
- Card grid of workflows: name, one-line description, meta (节点数 / 最近更新),
  last-run status badge, ⋯ menu (编辑 / 复制 / 导出 / 删除)
- Generate an empty-state variant too: no cards, centered guidance with two
  buttons 导入示例工作流 / 新建工作流
```

② 工作流编辑器：

```text
New screen, same shell, nav 工作流 active — 工作流编辑器: full-height canvas
with dot-grid background; vertical chain of 4 connected workflow nodes
(rounded cards: icon, node title, tool name); one node selected with highlight
border. Top bar: back arrow, editable workflow name, buttons 保存 / 试运行
(primary). Right side panel (节点设置): form with typed fields — text input,
folder picker row with browse button, dropdown, and expression-binding chips
like $inputs.url and $nodes.step1.outputs.path; panel footer 删除节点.
```

③ 任务中心 · 新建任务：

```text
New screen, same shell, nav 任务 active — 新建任务: left column = template
picker (list of workflow templates, one selected); right column = dynamic form
generated from the template inputs: text field, folder picker, single-select
radio group, multi-select checkboxes; primary button 执行.
```

④ 任务中心 · 历史记录：

```text
New screen, same shell, nav 任务 active — 任务历史: filter bar (name search,
status dropdown 全部/运行中/成功/失败); task rows: status badge (运行中 blue /
成功 green / 失败 red), task name, workflow name, start time, duration; one row
expanded showing per-node progress steps (checkmark / spinner / error icons)
and a streaming log console; actions 取消 / 重新运行 / 删除.
```

⑤ 工具与环境：

```text
New screen, same shell, nav 工具 active — top tabs 工具 | 环境. 工具 tab:
toolbar with 导入描述符 (primary); tool cards: icon, name, source badge
(内置 / 已导入), version, operation count, ⋯ menu (自定义路径 / 删除); plus an
empty-state variant with guidance 从 examples/ 导入工具描述符. 环境 tab: rows
for Java / Python / Node with detected install path, status badge 已检测 /
未配置, button 更改路径.
```

⑥ 设置 + 关于：

```text
New screen, same shell, nav 设置 active — grouped sections: 通用 (请求超时
slider, 系统通知 toggle default off); 外观 (浅色 / 深色 / 自动 segmented
control); 语言 (dropdown 简体中文 / English); 路径配置 (path rows with 浏览
button); footer links 诊断信息 / 关于. Also a simple 关于 panel: runtime info
rows (应用版本 / Electron / Node / Python) + backend health badge 正常.
```

⑦ 全局收尾（多选全部屏幕后）：

```text
Make the left sidebar, page header, spacing and typography identical across
all selected screens. Then produce a dark-mode version of every screen with
the same layout and accent color.
```
