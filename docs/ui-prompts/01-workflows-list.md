- **导航态**：工作流（选中）
- **前置**：先跑 [`00-shell.md`](./00-shell.md) 并在 Edit Theme 里锁定主题
- **功能元素来源**：[08 §3 · S1](../08-前端页面与功能清单.md)
- **本屏产出**：1 版常规（含卡片网格）+ 1 版空态；浅 / 深两态

## 提示词（逐字粘贴，不要改写）

```text
沿用同一外壳，导航「工作流」选中。屏幕：工作流列表。
- 工具栏：主按钮「新建工作流」，次按钮「导入」「导出」，一个搜索框，最右侧刷新按钮
- 工作流卡片网格（3 列）：每张卡片有名称、一句话描述、meta 行「12 个节点 · 2 小时前更新」、
  标签 chips（generic / report）、右下角 ⋯ 菜单（编辑 / 复制 / 试运行 / 导出 / 重命名 / 删除）
- 再出一版空状态：无卡片，居中引导插画与两行说明，两个按钮「导入示例工作流」「新建工作流」
```

> ⚠️ **本屏不要出现任何运行状态**：卡片上**没有**"上次成功 / 上次未成功 / 未运行"徽章、没有状态色点（2026-09-28 决策：本页只回答"有哪些工作流"，运行状态属于[运行记录](./05-run-records.md)）。"试运行"保留在 ⋯ 菜单里，但它是**一次性试跑**，不会把结果留在本页。
