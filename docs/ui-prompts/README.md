# UI 生成提示词（逐屏，直接粘贴）

> **这里是 UI 生成提示词的唯一来源。** 原先集中在 [08 §8](../08-前端页面与功能清单.md) 的「通用外壳 + ①～⑩」已按屏拆到本文件夹，一屏一文件，便于逐个粘贴到 [Google Stitch](https://stitch.withgoogle.com)（务必切 **Web** 模式，默认是移动端）。
> **逐字粘贴，不要改写。** 若生成结果与 [08 §3 屏幕清单](../08-前端页面与功能清单.md) 的功能元素冲突，**以 08 §3 为准**（功能元素不可删减）。

## 全局约定

- 画布 **1440×900**；**所有界面文字用简体中文**。
- **外壳只描述一次**：先跑 [`00-shell.md`](./00-shell.md)，在 Stitch 的 Edit Theme 里锁定主题（色板 / 圆角 / 字体），之后每屏都「沿用同一外壳」。
- 每屏都要出：**空态** + **浅色 / 深色两态**（"自动"等价于浅或深，不必单独出图）；加载中 / 错误态按 [08 §9 验收清单](../08-前端页面与功能清单.md) 要求。
- **S0 启动加载屏**沿用现有实现，不单独生成。
- **「关于」不单独出屏**：作为设置页的「关于」块（或 `/about` 二级页，内容相同），已含在 [`10-settings.md`](./10-settings.md) 内。
- 文案跑偏成英文时补一句：`把该屏所有界面文字改为简体中文`。
- 产出：设计稿截图放入 `.omo/designs/`（T24 消费）；可选 Figma / 代码导出。
