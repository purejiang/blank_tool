# ⑤ 任务 · 运行记录 `/tasks?tab=runs`

- **导航态**：任务（选中），顶部 tab「运行记录」高亮（另一个 tab 是「任务」，见 [`03-tasks-list.md`](./03-tasks-list.md)）
- **前置**：先跑 [`00-shell.md`](./00-shell.md) 并在 Edit Theme 里锁定主题
- **功能元素来源**：[08 §3 · S4](../08-前端页面与功能清单.md)
- **本屏产出**：1 版常规（含一行展开态）+ 1 版空态；浅 / 深两态
- **数据与口径**：这是**运行记录**（`history.list` 终态 + `run.list` 在跑合并），与「任务」tab 的任务定义是两份数据——运行记录会被保留策略（`max_runs` / `max_bytes`）自动裁剪，任务定义不会。`source = "inline"`（试运行 / 一次性）的记录没有任务名。
- **状态色**：运行中=蓝（带 spinner）、成功=绿、失败=红、已取消=灰——注意当前 `--app-*` 里**没有**「已取消」的灰、也没有 red 的弱背景（见 [design §3](../design.md)），实现阶段需补色，设计稿先定视觉。

## 提示词（逐字粘贴，不要改写）

```text
沿用同一外壳，导航「任务」选中，顶部两个 tab「任务」「运行记录」，当前是「运行记录」。
- 筛选栏：搜索框（按工作流名 / 任务名）、任务筛选下拉（全部任务 / 某个任务）、
  状态下拉（全部/运行中/成功/失败/已取消）、刷新按钮
- 列表：每行是状态徽章（运行中=蓝色带 spinner、成功=绿色、失败=红色、已取消=灰色）、
  任务名（没有任务名的显示灰色小字「（试运行 / 一次性）」）、工作流名、来源、开始时间、耗时、
  右侧 ⋯ 菜单（重新运行/打开目录/删除）
- 其中一行是展开态：下方显示逐节点进度步骤条（每步一个图标：✓ 完成、spinner 进行中、
  ✗ 失败、灰色跳过）与一块等宽字体的流式日志控制台
- 列表底部「加载更多」，上方一句灰色说明："运行记录按上限自动裁剪，任务本身不会被删除"
- 再出一版空状态：无记录，居中引导「还没有运行记录」，按钮「新建任务」
```
