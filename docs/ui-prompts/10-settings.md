# ⑩ 设置 `/settings`

- **导航态**：设置（选中）
- **前置**：先跑 [`00-shell.md`](./00-shell.md) 并在 Edit Theme 里锁定主题
- **功能元素来源**：[08 §3 · S7](../08-前端页面与功能清单.md)
- **本屏产出**：分组卡片（通用 / 外观 / 语言 / 路径 / 存储 / 关于）；浅 / 深两态
- **说明**：**「关于」不单独出屏**——它作为本屏底部的「关于」块（或 `/about` 二级页，内容相同）。存储分组的「一键清除全部」是危险操作，按 [08 §9](../08-前端页面与功能清单.md) 要求必须带后果说明。

## 提示词（逐字粘贴，不要改写）

```text
沿用同一外壳，导航「设置」选中。分组卡片纵向排列：
- 「外观」：语言下拉（简体中文 / English）+ 主题三选一（跟随系统 / 浅色 / 深色）
- 「行为」：系统通知开关（默认关闭）
- 「节点」：节点级默认设置卡片（当前无可配置项，仅一行灰色说明）
- 「日志」：日志级别下拉（Debug / Info / Warn / Error）
- 「路径」：**只有两行可改**——「工具链与运行时」（示例路径 …\runtime）与「后端目录」（示例路径 …\cli），
  每行是等宽路径 + 「浏览」按钮；卡片标题右侧一行灰色小字「改动需重启后端」，两行下方一行灰色帮助文字
  「工具链目录是「相对路径的工具描述符」（如 adb/adb.exe）与内置环境（Java 的 jre、Python 的 python）的解析根；
  后端目录默认即安装目录，只在排障时修改」。**不要**出现 server entry / runtime 可执行文件 / 输出 / 日志这四行，
  也不要给它们「浏览」按钮
- 「存储」：三行数据目录（任务目录 / 产物目录 / 日志目录），每行是**只读**绝对路径（等宽小字，
  示例 C:\Users\Administrator\AppData\Local\blanks\tasks）+ 右侧「大小 · 文件数」+ 一个「清除」危险按钮；
  卡片标题右侧显示合计大小；分组底部是「一键清除全部」危险按钮，下面一行橙红色警示文案：
  「输出目录包含已保存的工作流、任务与运行历史，一键清除会一并删除，且不可恢复」
- 「关于」块：版本信息行（应用版本 / Electron / Node / Python）与后端健康徽章「正常」；
  底部两个文字入口「诊断信息」「关于」
```

> ⚠️ 口径（2026-09-28）：① **任务**（任务定义，`<output>/task_defs/`）与**工作流**一样是用户数据，和运行历史（会被保留策略裁剪）不是一回事；存储分组的警示文案必须把"任务"列进去。后端默认已把 `templates/`、`task_defs/`、`history/`、`runs/`、`registry/` 与 `output/plugins.json` 从批量清除里排除（见 [08 §3 · S7](../08-前端页面与功能清单.md)）。② **数据目录不可配置**：`tasks` / `output` / `logs` 固定在 `%LOCALAPPDATA%\blanks\` 下，由主进程注入 `BT_*_DIR`；appConfig 里曾有的同名键已随 #19/WP10 删除（**"数据目录可配置"已明确不做**）——所以这三行只能**只读展示**，画成可改就是承诺做不到的事。③ **不要放「工具路径」卡片**：按工具的自定义路径收敛到 `/tools`（工具页），设置页只留一个跳转链接。
