# ③ 任务列表 `/tasks`（默认 tab）

- **导航态**：任务（选中），顶部 tab「任务」高亮（另一个 tab 是「运行记录」，见 [`05-run-records.md`](./05-run-records.md)）
- **前置**：先跑 [`00-shell.md`](./00-shell.md) 并在 Edit Theme 里锁定主题
- **功能元素来源**：[08 §3 · S3.1](../08-前端页面与功能清单.md)
- **本屏产出**：任务列表常规态 + 两种空态（无任务 / 无工作流）；浅 / 深两态
- **数据与口径**：`task.list` 返回的是**任务定义**——一个已保存工作流（按存储 id `workflow_id` 绑定，另有显示名） + 一套保存的入参（+ 可选工作目录）。任务在**第一次运行之前就存在**，且不会被运行历史的保留策略裁掉。列表项带存储 `id`（`tk-<12 hex>`），行内动作一律按 `id` 走（任务名可重复）。
- **与 `④ 任务编辑` 的分工**：本屏只做"看有哪些任务 + 运行 / 复制 / 删除"；**新建与改参在独立的二级页** [`04-tasks-editor.md`](./04-tasks-editor.md)（`/tasks/editor/:ref?`，`:ref` 是任务存储 id），与本屏是两个页面，不要合并成一屏。

## 提示词（逐字粘贴，不要改写）

```text
沿用同一外壳，导航「任务」选中，顶部两个 tab「任务」「运行记录」，当前是「任务」。
- 工具栏：主按钮「新建任务」，一个搜索框（按任务名 / 描述 / 绑定的工作流名），最右侧刷新按钮
- 任务列表（每行一张卡片或列表行）：
  - 任务名（如「每晚审计」）、一句话描述、绑定的工作流名（等宽小字，如 apk-audit）
  - meta 行：入参 3 项 · 2 小时前更新（若设了工作目录，再多一行等宽的目录路径）
  - 右侧操作：主按钮「运行」，次按钮「编辑」，⋯ 菜单（复制 / 查看运行记录 / 删除）
  - 其中一行演示「工作流已不存在」的警示态：绑定的工作流名旁边一个橙色警示徽章，
    「运行」按钮置灰不可点，提示需要重新选择工作流
- 不要出现任何运行状态徽章（成功 / 失败 / 运行中 / 未运行）——状态属于「运行记录」tab
- 再出一版空状态 1：还没有任务——居中引导「新建任务」，一句话说明"任务是保存了参数的工作流，
  建好之后可以反复运行"
- 再出一版空状态 2：一个任务都没有工作流可绑定——居中引导「去创建工作流」，按钮跳工作流页
```

> ⚠️ 本屏的「编辑」是**跳转到 `④ 任务编辑` 二级页**，不是弹窗、也不是本屏内的表单。
