# ⑥ 运行详情（抽屉）

- **形态**：从运行记录行展开的右侧抽屉（宽 640，占满高度）；[08 §3 · S5](../08-前端页面与功能清单.md) 说明它可升级为 `/tasks/:runId` 二级页
- **前置**：先跑 [`00-shell.md`](./00-shell.md)；本屏可与 [`05-run-records.md`](./05-run-records.md) 连做（同一外壳下的浮层）
- **功能元素来源**：[08 §3 · S5](../08-前端页面与功能清单.md)
- **本屏产出**：抽屉打开态 + 一个"没有任务名的记录"变体；浅 / 深两态
- **说明**：日志与逐节点进度从列表**移到本抽屉**（这是 07/08 早前提到的分工差异，以 08 为准）；列表行上的操作收敛为「重新运行 / 打开目录 / 删除」。**重新运行的语义随记录而变**：有任务名 → 用该任务**当前保存**的入参跑；没有任务名 → 用本记录的入参快照跑。

## 提示词（逐字粘贴，不要改写）

```text
同一外壳下，从运行记录右侧滑出一个运行详情抽屉（宽 640，占满高度）。
- 头部：状态徽章「失败」、任务名「每晚审计」（次要样式一行小字）、工作流名、run_id（等宽小字）、
  开始时间、耗时「4.2 s」，右上角关闭按钮
- 分区「输入」：两列表格（target_dir → D:\projects\demo，带「打开」小按钮；min_matches → 3）
- 分区「节点进度」：纵向时间线，每步一行——状态图标、节点名（含嵌套路径如 loop/0/step 的缩进）、
  耗时、尝试次数「第 2 次尝试」、失败时下方一行红字错误信息
- 分区「输出」：其中一个值是红色边框的截断提示块：「内容过大已截断 · 原长 128 KB · 点击查看预览」
- 分区「日志」：等宽字体控制台，右上角「打开日志文件」「刷新」；底部一行「共 12.4 KB，已完整显示」
- 底部操作条：「重新运行」「打开运行目录」「删除记录」
- 再出一版头部变体：这条记录没有任务名（来自试运行或一次性执行）——任务名位置显示灰色小字
  「（试运行 / 一次性）」，并在旁边给一个次要按钮「存为任务」
```
