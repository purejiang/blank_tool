# ② 工作流编辑器 `/workflows/editor/:name`

- **导航态**：工作流（选中）
- **前置**：先跑 [`00-shell.md`](./00-shell.md) 并在 Edit Theme 里锁定主题
- **功能元素来源**：[08 §3 · S2](../08-前端页面与功能清单.md)
- **本屏产出**：1 版常规（三栏 + 选中节点）+ 1 版未选中节点（右栏整体不显示）+ 1 版选中端点（工作流入参）+ 1 版出边冲突警告态；浅 / 深两态
- **说明**：第 3 个变体是「开始 / 结束」端点的检查器（入参 / 出参各一侧，见 [08 §3 · S2](../08-前端页面与功能清单.md)）；第 4 个变体对应 [08 §9 验收清单](../08-前端页面与功能清单.md) 里的「S2 线性模型守卫」——画布出现多余出边时要实时警告、逐条列出连线、阻断保存。

## 提示词（逐字粘贴，不要改写）

```text
沿用同一外壳，导航「工作流」选中。屏幕：工作流编辑器，三栏。
- 顶栏：返回箭头、只读工作流名「release-check」+ 紧随其后的「编辑信息」铅笔按钮（点开是名称/版本/描述弹窗）、
  次按钮「问题」，右侧「保存」「试运行」（主按钮）
- 左栏（工具面板，208px）：搜索框；分组「内置」「已导入」；每个工具是一行——图标、名称（如 file.read）、
  一句话描述、右侧拖拽手柄；有一行是禁用态（灰色 + 不可拖拽）
- 中间画布：点阵网格背景，横向链式相连节点，**两端是虚线药丸形的虚拟端点「开始」「结束」**；
  节点是圆角卡片（图标 + 节点名 + 工具名/操作名），每个节点左右各有端口圆点，其中一个节点被选中（蓝色描边）；
  画布右下角缩放控件与小地图
- 右栏（选中对象检查器，280px）：工具名与描述；「操作」下拉；下面是类型化表单——文本输入框、
  目录选择行（路径 + 浏览按钮）、开关、JSON 等宽文本域；输入框下方是表达式绑定 chips
  （$inputs.target_dir、$nodes.scan.outputs.count）；「失败策略」下拉（终止/跳过）与「重试次数」数字框；
  面板底部一行红字错误提示与「保存」「删除节点」按钮
- 再出一版：未选中节点时右栏整体不显示（画布占满宽度），不是空态面板
- 再出一版：选中「开始」端点时右栏变成**工作流入参**编辑（端口列表 + 「新增入参」按钮，没有 inputs/outputs 切换 tab）；
  选中「结束」端点时同一位置是**工作流输出**编辑
- 再出一版：画布出边冲突的警告态——画布上方一条 warning 条，第一行一句结论
  （「有 1 条连线不会被保存：每个节点只保留第一条出边」），第二行列出「tool-exec-shell-2 → tool-file-write-3」，
  第三行灰色小字说明分支应改用 flow.foreach 等组合工具；同时「保存」呈失败/禁用态
```
