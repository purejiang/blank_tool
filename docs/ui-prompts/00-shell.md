# 通用外壳（先跑这一条）

- **顺序**：第 1 条，本组提示词的基线。
- **生成后必做**：在 Stitch 的 **Edit Theme** 里锁定主题（色板 / 圆角 / 字体），后续每屏会自动保持一致。
- **功能元素来源**：[08 §2 信息架构与外壳](../08-前端页面与功能清单.md)、[07 §1](../07-UI设计规范.md)（外壳冻结契约）
- **注意**：外壳在后续 12 条里都写作「沿用同一外壳」，因此这一条必须先跑；侧边栏结构（应用名 + 折叠按钮 + 4 项导航 + 主题切换 + 页脚健康圆点/版本号）此后不得再改——**一级导航项是 4 个**（工作流 / 任务 / 工具 / 设置），工具下的「工具 / 环境 / 插件」三个页面共用「工具」这一项，不要在侧边栏里再拆出「环境」「插件」。

## 提示词（逐字粘贴，不要改写）

```text
设计一个桌面应用（1440×900）：「Blank」——面向开发者好普通用户的本地工作流编排应用，
所有界面文字用简体中文。
外壳（所有屏幕必须完全一致）：左侧窄边栏——顶部应用名 "Blank" 与折叠按钮，
中部 4 个带图标导航项：工作流（选中）、任务、工具、设置，底部是主题切换；
边栏页脚显示后端健康小圆点与版本号 "app 2.3.0 | cli 1.0.1"。
右侧分为顶部标题区+内容区：页面标题 + 一句话描述，下面是内容区。
整体风格：大圆角、极简风格
```
